# jev-state

This project is a state management visualizer for Jev.

Use the TypeSafe skill for work on this project. Read
`.agents/skills/typesafe-ai/SKILL.md` and follow its guidance, including consulting
the current TypeSafe documentation before implementing integrations.

Keep operator TypeSafe API credentials server-side and out of version control.
User-supplied keys may be held in the current browser tab's memory, as explicitly
requested by the owner. Send them only to the same-origin API for provider checks
and live requests. Never persist personal keys in browser storage, cookies,
workspace exports, a server database, or logs.
